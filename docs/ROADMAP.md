# 開發路線圖 Roadmap

## 一、Sprite Sheet 規格（已在 V1.3 實作，供未來手繪美術替換）
| 項目 | 規格 |
|---|---|
| 畫格大小 | 48×48 px，透明背景 |
| 排列 | 單列橫向，每個型態一張 `art/sheet-<型態>.png` |
| 調色盤 | 每型態約 12 色＋自動深色描邊（outline） |
| 光源 | 左上方；右下為陰影色 |
| 地面線 | 第 44 列為腳底，所有型態對齊 |
| 畫格順序 | idle0, idle1, blink, eat0–2, jump0–2, wash0–1, sleep0–1, happy0–1, sad0–1, tired0–1, shy0 |
| 動畫 | idle 2.5 fps、eat 7 fps、play 11 fps、wash 8 fps、sleep 1.5 fps |

> 未來若要換成手繪 PNG：照上表順序畫好，取代程式產生的畫格即可，遊戲邏輯不必改。

## 二、進化系統

> V1.11 起共 7 系：🔥焰 💧潮 🌿森 🪨土 🐦鳥 ⚡電 ⚙️金。V1.12 起屬性在蛋裡決定、一路長到高階（下方舊圖中依照顧方式分支的設計已經不再使用）。
V1.4 起每顆蛋由隨機「基因」決定外觀（體色、耳角、頭頂、尾巴、花紋、眼睛、翅膀、稀有度），
進化時保留基因並依路線加上新部位。下圖為經典種的路線：
```
蛋 ─(點 5 下)→ 露露獸 Lulu（幼年期 Lv.1–4）
                 └─ Lv.5 依照顧次數決定 ─┬→ 🔥 焰角獸 Ember Horn（玩耍最多）
                                         ├→ 💧 霧鰭獸 Mist Fin（洗澡最多）
                                         └→ 🌿 森羽獸 Sylvan Wing（餵食＋摸摸最多）
V1.4 預定：Lv.12 第三階段「完全體」，每條路線再依「心情平均值」分 2 種 → 共 6 種
```

## 三、版本規劃

### V1.9（下一步）
- 介面分頁（主頁／家園／冒險／圖鑑／日記）、背景音樂。
- 親密度更多專屬動作與日記事件。

### V1.3.x（下一步，小修）
- 依你的 iPhone 實機回報修正版面與觸控。
- 個性系統：活潑／溫和／貪吃，影響對話與待機動作。

### V1.6
- 同時飼養多隻；即時連線配對與對戰（需要伺服器，例如 Firebase，需另評估費用與隱私）。
- V2.0 原生 App 可直接讀取 HealthKit（健康）步數，不必使用捷徑。
- 商店：食物種類（蘋果、魚、星星糖）、肥皂、玩具；金幣用途。
- 房間裝潢：地毯、床、植物，可擺放（場景改為 室內／戶外 切換）。
- 第三階段進化（6 種）。

### V1.6
- 小遊戲：接蘋果、記憶翻牌（賺金幣）。
- 成就系統、隱藏事件（下雨天、生日、半夜驚喜）。
- 背景音樂（BGM）。

### V2.0 原生 iOS App / TestFlight
**重點：不需要自己買 Mac。**
1. 用 Capacitor（把網頁包成原生 App 的工具）包裝現有遊戲。
2. 用 GitHub Actions（GitHub 的雲端自動化）提供的 macOS 雲端主機執行 Xcode 編譯。
3. 用 fastlane（自動化上架工具）＋ App Store Connect API 金鑰，在雲端完成簽署並上傳到 TestFlight（蘋果測試發布平台）。

**一定需要的：**
- Apple Developer Program（蘋果開發者計畫）：**每年 99 美元**（以當地貨幣計價），沒有它就無法簽署、上 TestFlight 或 App Store。
- 由你本人在 iPhone Safari 完成：註冊付款、在 App Store Connect 建立 App、產生 API 金鑰並貼到 GitHub Secrets（加密設定）。

**做不到的：** 只靠 iPhone 本機直接產生「已簽署 .ipa」並安裝——必須經過蘋果簽署流程。
