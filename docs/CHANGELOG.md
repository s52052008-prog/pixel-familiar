# 更新紀錄 Changelog

## V1.3.0（2026-11-16）— Claude 接手重製
### 修正 V1.2 錯誤
- 升級訊息被同一動作的訊息覆蓋 → 改為訊息佇列（queue），升級訊息會接著顯示。
- 洗澡／睡覺可無限刷經驗值與金幣 → 數值已滿時拒絕動作；數值越需要照顧，經驗越多；動作播放期間忽略連點。
- 存檔寫入失敗會讓遊戲當掉 → 安全儲存，失敗時顯示警告、遊戲繼續。
- 存檔損壞就歸零 → 每分鐘保留一份備份，主存檔損壞時自動還原。
- 主畫面圖示用 SVG（iPhone 不支援）→ 改為 PNG 180/192/512。
- `prompt / alert / confirm` 系統彈窗 → 全部改成遊戲內對話框。
- `www/` 部署路徑問題 → 檔案移到根目錄。

### 新功能
- **真正逐格像素動畫**：程式產生 sprite sheet，每格 48×48，共 19 個畫格（待機、眨眼、吃×3、跳×3、洗×2、睡×2、開心×2、難過×2、疲倦×2、害羞）。
- **像素蛋**：點 5 下逐步裂開、搖晃後孵化，孵化後立刻取名。
- **三條進化路線**（Lv.5）：🔥 焰角獸（玩耍）、💧 霧鰭獸（洗澡）、🌿 森羽獸（餵食＋摸摸），含發光剪影進化演出與圖鑑。
- **真的睡覺**：體力每分鐘 +15，睡飽自動醒，可手動叫醒；離線期間也會正確計算。
- 數值過低會讓心情下降更快、角色顯示難過／疲倦動畫。
- **匯出／匯入存檔**：存檔碼（含校驗碼防止貼錯）、存成檔案、從檔案匯入。
- V1.x 舊存檔（`pixel-familiar-v1`）自動搬移，舊資料不刪除。
- 晝夜場景（依手機時間：白天／黃昏／夜晚）、像素圖示、8-bit 音效（可關閉）。
- iPhone 安全區域（瀏海／動態島／底部橫條）、防雙擊縮放、首次「加入主畫面」提示。
- 離線快取（Service Worker 網路優先＋3 秒逾時退回快取）。
- 選單內可直接檢視 Sprite Sheet、檢查更新。

### 移除
- Capacitor（原生封裝工具）設定暫時移除，V2.0 再以正確結構加回（見路線圖）。
