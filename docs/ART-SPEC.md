# 美術交付規格（給 GPT 等 AI 繪圖用）

## 一、要交的圖
| 項目 | 規格 |
|---|---|
| 數量 | 7 屬性 × 4 階段（幼年／少年／成年／高階）＝ 28 隻，每隻 2 張：**睜眼**、**閉眼** |
| 尺寸 | 正方形，1024×1024 即可（我會縮成遊戲用的 48×48） |
| 背景 | 純色、單一顏色，建議亮綠色 #00FF00（不要透明、不要場景、不要陰影） |
| 角度 | 正面、面向鏡頭、站立、左右大致對稱，四隻腳或兩隻腳都在畫面下方 |
| 構圖 | 一張圖只有一隻、置中、身體約占畫面寬度 60–70%，四周留白 |
| 風格 | 16-bit 像素風、粗黑描邊、色數少（約 16 色內）、光源在左上 |
| 檔名 | `屬性_階段_眼睛.png`，例如 `flame_3_adult_open.png`、`flame_3_adult_closed.png` |
| 屬性代號 | flame 火、tide 水、forest 森、earth 土、bird 鳥、elec 電、metal 金 |
| 階段代號 | 1_juvenile、2_teen、3_adult、4_ascended |

## 二、我會怎麼處理
1. 去背、縮成 48×48，並統一調色盤與描邊。
2. 用睜眼／閉眼兩張，自動做出待機、眨眼、吃、跳、洗、睡、開心、難過等 19 個動畫畫格。
3. 隨機物種改成在這些造型上做「顏色深淺、花紋、稀有光芒」的變化。
4. AI 生圖的格線常常不整齊，我會修正；不像同一隻的圖，會請你重畫那一張。

## 三、注意
- 必須是**原創**角色，不要像寶可夢、數碼寶貝等現有角色（尤其電系不要做成「黃色老鼠＋紅臉頰＋閃電尾巴」）。
- 同一屬性的 4 個階段要看得出是**同一隻長大**：顏色、臉型、招牌特徵要延續。
